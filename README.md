## Project Structure

The application uses a modular component-based structure:

```text
portfolio/
├── public/                # Static assets
├── src/
│   ├── components/        # Reusable UI components
│   │   ├── About/
│   │   ├── Background/
│   │   ├── Contact/
│   │   ├── Cursor/
│   │   ├── Hero/
│   │   ├── Marquee/
│   │   ├── Nav/
│   │   ├── Preloader/
│   │   ├── RippleCanvas/
│   │   ├── SideNav/
│   │   └── Work/
│   ├── js/                # Utility scripts
│   ├── assets/            # Project assets
│   ├── App.jsx            # Main application component
│   ├── index.css          # Global Tailwind styles
│   └── main.jsx           # React entry point
├── index.html             # Main HTML entry
├── package.json           # Dependencies
└── vite.config.js         # Build configuration
```

Each major section is organized into reusable components to keep the project clean, maintainable, and easy to extend.

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed on your system.

### Create the Project

Create a new React project using Vite:

```bash
npm create vite@latest portfolio
```

Select:

- Framework: React
- Variant: JavaScript

Then move into the project directory:

```bash
cd portfolio
```

### Install Dependencies

Install the project dependencies:

```bash
npm install
```

Install the animation library:

```bash
npm install gsap
```

### Run the Development Server

Start the development server:

```bash
npm run dev
```

The application will be available at: `http://localhost:5173`

### Build for Production

Create an optimized production build:

```bash
npm run build
```

### Preview the Production Build

```bash
npm run preview
```
